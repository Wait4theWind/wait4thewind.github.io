CF279B - Books 题解

题目简介

Valera 有 $t$ 分钟的空闲时间，从图书馆借了 $n$ 本书，读完第 $i$ 本需要 $a_i$ 分钟。他会任选一本编号 $i$ 的书，然后从这本开始一本接一本地读下去（$i, i+1, i+2, \dots$），直到空闲时间用完或读完了第 $n$ 本为止；每本书都必须完整读完（剩余时间不够就不会开始读）。求他最多能读多少本书。

数据范围：$1 \le n \le 10^5$，$1 \le t \le 10^9$，$1 \le a_i \le 10^4$。

思路

Valera 从某本书 $i$ 开始一本接一本地读，因此他读的书一定是一段连续区间 $[i, r]$。又因为每本书的时间 $a_i \ge 1$，区间越长总时间越大——所以固定起点 $i$ 时，能读的书数就是「以 $i$ 为左端点、区间和不超过 $t$ 的最长区间长度」。

于是问题转化为：求最长的连续子数组，使其元素和 $\le t$。

由于所有 $a_i > 0$，区间和随右端点单调递增，可以用滑动窗口（双指针）：

  1. 维护窗口 $[l, r]$ 与窗口内的剩余可用时间；
  2. 对每个左端点 $l$，尽量把 $r$ 向右扩展，直到再加一本就超时；
  3. 记录当前窗口长度并取最大值；
  4. 左端点右移一格，把 $a_l$ 移出窗口（归还时间），继续。

关键观察

  • 读的书必须连续 $\Rightarrow$ 连续子数组问题。
  • $a_i \ge 1$（严格为正）$\Rightarrow$ 区间和随右端点单调不减 $\Rightarrow$ 双指针可行，且两个指针各自单调右移，总移动次数 $O(n)$。

正确性说明

对每个左端点 $l$，滑动窗口得到的 $r$ 是满足 $\sum_{k=l}^{r} a_k \le t$ 的最大右端点：一旦加入 $a_{r+1}$ 就超过 $t$，而所有 $a_i$ 为正，之后只会更大。因此以 $l$ 为起点能读的最大书数为 $r - l + 1$。对所有 $l$ 取最大值，即为所求答案。

复杂度

  • 时间复杂度：$O(n)$。左右指针都只单调右移，每个位置最多被访问常数次。
  • 空间复杂度：$O(n)$，用于存储数组 $a$。

我的错误与反思

训练过程中出现 1 处真实错误：内层循环死循环。

最初的写法是：

当 if 条件不成立（下一本书放不下）时，循环体什么都不做，r_book 不变，而 while (r_book <= n) 依然为真，于是空转成死循环，程序超时（--dry-run 直接卡死）。

修正：扩展不动时跳出循环——

反思：写 while + if 结构时，必须保证循环每轮都朝终止方向推进。若 if 不成立时循环变量不改变，就会空转。以后遇到这类「扩展型」循环，应把边界条件直接写进 while 判断（如 while (r < n && cur_t >= a[r + 1])），或确保有 else break。

本题未记录其他明显错误。

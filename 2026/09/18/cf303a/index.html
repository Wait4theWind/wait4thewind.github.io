CF303A - Lucky Permutation Triple 题解

题目简介

长度为 $n$ 的排列（permutation）是 $0,1,\dots,n-1$ 的一个排列。给定 $n$，要找出三个长度为 $n$ 的排列 $a,b,c$，使得对每个位置 $i$ 都满足

$$(a_i + b_i) \bmod n = c_i$$

如果不存在则输出 -1；存在则输出任意一组解。

数据范围：$1 \le n \le 10^5$。

思路

第一步：判断有无解。

三个排列各自的和都是 $\frac{n(n-1)}{2}$。注意 $a_i, b_i \le n-1$，所以 $a_i + b_i \le 2n-2 < 2n$，即每个位置至多”绕一圈”。设满足 $a_i + b_i \ge n$ 的位置有 $k$ 个，则

$$\sum c_i = \sum (a_i + b_i) - k \cdot n = n(n-1) - kn$$

又 $\sum c_i = \frac{n(n-1)}{2}$，联立得 $kn = \frac{n(n-1)}{2}$，即

$$k = \frac{n-1}{2}$$

所以 $n$ 必须是奇数，否则无解，输出 -1。

第二步：构造。

取最朴素的方案：

  • $a_i = i$（恒等排列）；
  • $b$ 取一个”轮转”：$b_0 = n-1$，$b_i = i-1\ (i \ge 1)$；
  • 令 $c_i = (a_i + b_i) \bmod n$。

关键观察

  • 用总和作为全局不变量，可以一次性确定”绕圈位置数” $k = \frac{n-1}{2}$，从而得到存在性条件：$n$ 为奇数。
  • 构造时让 $b_i = (i-1) \bmod n$，则 $c_i = (i + b_i) \bmod n = (2i-1) \bmod n$。因为 $n$ 为奇数时 $\gcd(2,n)=1$，所以 $i \mapsto (2i-1) \bmod n$ 是一个双射，$c$ 自然也是排列。

正确性说明

  • $a_i = i$ 显然是 $0..n-1$ 的排列。
  • $b = [n-1, 0, 1, \dots, n-2]$ 是 $0..n-1$ 的排列（一次循环移位）。
  • $c_i = (2i-1) \bmod n$：当 $n$ 为奇数时，$i \mapsto (2i-1) \bmod n$ 是双射，因此 $c$ 也是 $0..n-1$ 的排列。
  • 且每个 $i$ 都按定义满足 $(a_i + b_i) \bmod n = c_i$。

其中「$n$ 为奇数时 $i \mapsto (2i-1) \bmod n$ 是双射」的证明（只需证单射）：

假设 $2i-1 \equiv 2j-1 \pmod n$，两边加 $1$ 得 $2(i-j) \equiv 0 \pmod n$，即 $n \mid 2(i-j)$。因为 $n$ 为奇数，$\gcd(2,n)=1$，故 $n \mid (i-j)$。而 $i,j \in [0, n-1]$，所以 $|i-j| < n$，只能 $i=j$。

直观理解：减 $1$ 是模 $n$ 环上的平移（显然是双射），关键在乘 $2$；而 $2$ 可逆当且仅当 $\gcd(2,n)=1$，即 $n$ 为奇数（此时 $2$ 的逆元是 $\frac{n+1}{2}$）。

因此当 $n$ 为奇数时该构造合法；当 $n$ 为偶数时由总和论证可知无解。

复杂度

  • 时间复杂度：$O(n)$。
  • 空间复杂度：$O(n)$。

我的错误与反思

本题为构造题，训练过程中出现 2 处真实错误：

  1. b 数组不是排列。 最初写成

    这个循环把 b[0] 又覆盖成了 0，同时 b[n-1] 从未被赋值，导致 b 出现重复元素、缺少元素，不是排列。

    修正：轮转应写成 b[0] = n-1; for (int i = 1; i < n; ++i) b[i] = i-1;。

  2. 输出格式错误。 打印 c 时把 endl 放在了循环内部：

    结果每个数各占一行。题目要求每个排列占一行，应改为循环内只输出 " "，循环外再 endl。

反思：构造题要逐项验证产物是否是合法对象（排列是否每个数恰好一次、输出格式是否符合要求），而不是只看”大概能跑”。这两处都属于实现细节，和之前 CF180C 的边界问题、CF279B 的死循环同类——实现细节的严谨性仍需加强。

本题未记录其他明显错误。

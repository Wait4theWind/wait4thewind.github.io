Codeforces Round 1114 (Div. 3) 题解

赛后总结

复健的第一场CF，Div3 但是只做出来 4/8，感觉状态不好，简单的 D 和 E 没做出来或没时间做

C2. Marenol (hard version)

在做 C1 的过程中，我们已经知道两个字符串能互相转换的条件是奇偶位置字符的 $0$ 和 $1$ 的数量相等

C2 问我们将两个字符串转化的最少步骤

一开始看感觉像是逆序对问题，但后来发现是想多了

只要将两个串的奇偶位置分别从左到右按顺序匹配 $1$ 就可以了，$1$ 匹配好了 $0$ 的位置自然正确

怎么证明这样顺序匹配是正确的呢？

对于任意的 $i<j$，将 A 串的 $a_i$ 和 $a_j$ 和 B 串的 $b_i$ 和 $b_j$ 匹配的成本为

$$d = \lvert a_i - b_i \rvert + \lvert a_j - b_j \rvert$$

如果交叉匹配，成本为

$$D = \lvert a_i - b_j \rvert + \lvert a_j - b_i \rvert$$

不妨设 $a_i < b_i$

分三种情况：

  • $a_i < a_j \leq b_i < b_j$ 时，$d = b_i + b_j - a_i - a_j = D$
  • $a_i < b_i < a_j \leq b_j$ 时，$d = b_i + b_j - a_i -a_j<a_j+b_j-a_i-b_i=D$
  • $a_i < b_i < b_j < a_j$ 时，$d=b_i+a_j-b_j-a_i<b_j+a_j-a_i-b_i=D$

综上 $d \leq D$

D. Silhouette

这题思维难度不大，但是比赛时候没做出来，感觉思路没问题，就是过不掉

结果赛后发现，我虽然给数组都开 longlong 了，但是中间有个重要的过程量是 int 溢出了，气死我了

$b_{i}$ 越小，对应的 $a_i$ 就越小

先把 $b$ 排序，将相同值合并，不同值差分除以数量就得到了 $a_i$，再放回原来的位置

最后的 $b_n$ 以及和 $b_n$ 值相同的元素对应的 $a_i$ 就是上一个 $a_i$ 加一即可（因为除了要比 $last _ val$ 大没有别的限制）

注意一些细节，比如得到的 $a_i$ 值应该是单调递增的，还有要是正整数（能除尽），以及最重要的开 longlong（TAT）

E. Chronostasis

比赛时没时间（一直在调 D 题）导致题目都没看，结果补题时一看怎么这么简单

很显然的贪心，每次加上一个尽可能小的 $b_i$ 满足 $a_i > 0$ 即可

用一个 multiset 就可以轻松实现了

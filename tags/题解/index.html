CF303A - Lucky Permutation Triple 题解

题目简介

长度为 $n$ 的排列（permutation）是 $0,1,\dots,n-1$ 的一个排列。给定 $n$，要找出三个长度为 $n$ 的排列 $a,b,c$，使得对每个位置 $i$ 都满足

$$(a_i + b_i) \bmod n = c_i$$

如果不存在则输出 -1；存在则输出任意一组解。

数据范围：$1 \le n \le 10^5$。

CF279B - Books 题解

题目简介

Valera 有 $t$ 分钟的空闲时间，从图书馆借了 $n$ 本书，读完第 $i$ 本需要 $a_i$ 分钟。他会任选一本编号 $i$ 的书，然后从这本开始一本接一本地读下去（$i, i+1, i+2, \dots$），直到空闲时间用完或读完了第 $n$ 本为止；每本书都必须完整读完（剩余时间不够就不会开始读）。求他最多能读多少本书。

数据范围：$1 \le n \le 10^5$，$1 \le t \le 10^9$，$1 \le a_i \le 10^4$。
